Buscar Cliente

Digite o nome, CPF ou telefone para encontrar um cliente

Como usar o sistema

1. Digite o nome, CPF ou telefone do cliente na barra de busca

2. Selecione o cliente nas sugestões que aparecem

3. Se o cliente não estiver cadastrado, clique em "Cadastrar agora"

4. Após selecionar o cliente, você poderá iniciar uma nova venda
