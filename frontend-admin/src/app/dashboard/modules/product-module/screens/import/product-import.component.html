Importar Produtos

Faça upload de um arquivo para importar produtos

Formatos suportados: .xls, .xlsx, .csv

Tamanho máximo: 1MB

Instruções:

  • Certifique-se de que o arquivo esteja no formato correto (.xls, .xlsx ou .csv).
  • Na coluna "Categoria", coloque o ID da categoria, que pode ser encontrado na aba "Categoria" do arquivo XLS.
  • Caso a categoria não exista, o campo sinalizará um erro.
  • Verifique se todos os campos obrigatórios estão preenchidos antes de importar.
